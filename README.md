## Язык ассемблера

| Выражение | Смысл | Поля |
|---|---|---|
| `mem[B] = C` | Записать константу | A=195, B, C |
| `mem[C] = mem[mem[B]]` | Косвенное чтение | A=6, B, C |
| `mem[B] = mem[C]` | Прямое копирование | A=104, B, C |
| `mem[B] = sqrt(mem[mem[C]])` | Корень косвенного операнда | A=80, B, C |

Адреса находятся в диапазоне 0–1023, константы — 0–32767.
Допустимы пробелы, пустые строки и комментарии после `#`.
Одна инструкция занимает одну строку. Метки и циклы не предусмотрены.

## Запуск

Требуется Python 3.10 или новее, сторонних зависимостей нет.

```powershell
py -3 src/assembler.py examples/spec.asm build/spec.bin --test
```

Ассемблер записывает бинарный файл и число инструкций. С `--test`
выводятся поля A/B/C и байты. Порядок байтов little-endian, размеры
команд 5 байт для загрузки константы и 4 байта для остальных операций.
Неиспользуемые старшие биты равны нулю.

Проверка тестов методички:

```powershell
py -3 -m unittest discover -s tests -v
```

## Память и интерпретатор

Общая память содержит 1024 числовые ячейки. Бинарный код загружается
в начало этой же памяти, по одному байту на адрес. Данные могут быть
целыми или вещественными числами. Примеры размещают данные с адреса 512,
чтобы не затирать код. Запись в адрес кода разрешена и влияет на следующий
цикл выборки инструкции. Указатели проверяются на целочисленность и границы.
Выполнение заканчивается при достижении конца исходного бинарного файла.

```powershell
py -3 src/assembler.py examples/copy.asm build/copy.bin
py -3 src/interpreter.py build/copy.bin build/copy.json --start 600 --end 602
```

В JSON сохраняются поля start, end и memory. Обе границы включены.
Ожидаемый результат копирования — 7, 11, 19.

## Арифметика

`sqrt` читает указатель из mem[C], затем операнд из mem[mem[C]].
Вычисленный вещественный корень записывается в mem[B]. Дробная часть
сохраняется. Отрицательные и нечисловые указатели, выход за границы,
отрицательные и бесконечные операнды приводят к диагностике с адресом PC.

```powershell
py -3 src/assembler.py examples/sqrt.asm build/sqrt.bin
py -3 src/interpreter.py build/sqrt.bin build/sqrt.json --start 600 --end 600
```

Результат в ячейке 600 равен 3.0.

## Файлы и функции

- `instructions.py` задаёт опкоды, размеры полей и объект Instruction.
- `parser.py` разбирает алгебраические выражения и сообщает номер ошибки.
- `codec.py` упаковывает поля и декодирует инструкцию по текущему PC.
- `assembler.py` читает текст, проверяет его целиком и записывает бинарник.
- `machine.py` выполняет команды в общей памяти и формирует дамп.
- `interpreter.py` проверяет диапазон и сохраняет JSON после исполнения.
- `demo.py` запускает проверки и все примеры через CLI.
- `tests/` содержит проверки синтаксиса, байтов, памяти, АЛУ и векторов.

## Диагностика

Ошибки ассемблера и интерпретатора возвращают код завершения 1.
Проверяются синтаксис, диапазоны полей, неизвестные опкоды, обрезанные
команды, ненулевые резервные биты, указатели, диапазон дампа и sqrt.
При ошибке исполнения новый дамп не записывается. Если по тому же пути
уже был файл предыдущего запуска, он сохраняется и не является новым
результатом. Успешный код завершения — 0.

Не следует размещать данные поверх ещё не выполненных команд, если
самоизменение кода не является целью программы. Интерпретатор читает
из общей памяти при каждом шаге и обнаруживает повреждение инструкции.

4. Косвенная операция sqrt и проверки операндов.

Каждый этап сохранён отдельным коммитом. Требуется только стандартная
библиотека Python. Программа исполняет собственный бинарный формат УВМ.
