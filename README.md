# Practice 3 Variant 24

Урсу Никита Юрьевич, ИКБО-16-25.

Ассемблер и интерпретатор учебной виртуальной машины.
Исходное задание — вариант 24, страницы 100–103.

## Язык ассемблера

| Выражение | Смысл | Поля |
|---|---|---|
| `mem[B] = C` | Записать константу | A=195, B, C |
| `mem[C] = mem[mem[B]]` | Косвенное чтение | A=6, B, C |
| `mem[B] = mem[C]` | Прямое копирование | A=104, B, C |
| `mem[B] = sqrt(mem[mem[C]])` | Корень косвенного операнда | A=80, B, C |

Адреса находятся в диапазоне 0–1023, константы — 0–32767.
Допустимы пробелы, пустые строки и комментарии после `#`.
Одна инструкция занимает одну строку. Метки и циклы не предусмотрены.

## Запуск

Требуется Python 3.10 или новее, сторонних зависимостей нет.

```powershell
py -3 src/assembler.py examples/spec.asm build/spec.bin --test
```

Ассемблер записывает бинарный файл и число инструкций. С `--test`
выводятся поля A/B/C и байты. Порядок байтов little-endian, размеры
команд 5 байт для загрузки константы и 4 байта для остальных операций.
Неиспользуемые старшие биты равны нулю.

Проверка тестов методички:

```powershell
py -3 -m unittest discover -s tests -v
```

## Память и интерпретатор

Общая память содержит 1024 числовые ячейки. Бинарный код загружается
в начало этой же памяти, по одному байту на адрес. Данные могут быть
целыми или вещественными числами. Примеры размещают данные с адреса 512,
чтобы не затирать код. Запись в адрес кода разрешена и влияет на следующий
цикл выборки инструкции. Указатели проверяются на целочисленность и границы.
Выполнение заканчивается при достижении конца исходного бинарного файла.

```powershell
py -3 src/assembler.py examples/copy.asm build/copy.bin
py -3 src/interpreter.py build/copy.bin build/copy.json --start 600 --end 602
```

В JSON сохраняются поля start, end и memory. Обе границы включены.
Ожидаемый результат копирования — 7, 11, 19.
